# 💻 Tecboard

Tecboard is a responsive landing page created to present a monitoring solution that helps users keep track of their applications and receive alerts when something goes wrong.

The project focuses on a modern dark interface, clean typography and interactive visual elements.

## 🛠️ Technologies

- HTML5
- CSS3
- Google Fonts (Poppins)

## 📚 What I Learned

- HTML semantic structure.
- CSS Flexbox and positioning.
- Responsive design with Media Queries.
- CSS hover effects and transitions.
- Working with external fonts and image assets.

## 🎯 Purpose

This project was developed as part of my journey in learning web development, improving my HTML and CSS skills through practical projects.
